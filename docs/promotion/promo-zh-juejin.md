# 掘金长文（草稿）

## 标题建议

我把 2600+ 个 DeepSeek Harness 插件全扒了一遍，做了个每小时自动更新的目录

## 正文大纲

### 1. 背景：DSH 生态一夜爆发

DeepSeek Harness（`dsh`）开源不到一周，GitHub 已破 10 万 star。"一切皆插件"的架构让插件生态指数级增长：官方 `dsh-plugin` 话题下已有 2600+ 仓库，每天还在新增。

但生态太新，找插件的方式基本靠：

- 翻 GitHub topic，按 star 排序，逐个人工判断
- 看几份人工精选清单，但更新慢、覆盖面小

### 2. 我的方案：全量 + 自动化 + 机器可读

**awesome-dsh-hub** 是一个自动维护的插件目录，核心设计：

- **准入标准明确**：有 `dsh-plugin` 话题 + 根目录 `package.json` 声明 `dsh.bundle.patch`，自动收录
- **全量覆盖**：按 star 区间分段查询，绕过 GitHub 搜索 1000 条上限，监测全部 2600+ 仓库
- **每小时刷新**：新插件 1 小时内自动出现，无需人工申请
- **标准 JSON API**：`registry/plugins.json`，每项含名称、仓库、描述、star、许可证、分类、活跃度、安装命令
- **检索站点**：搜索 + 多重筛选 + 一键复制安装命令 + 中英切换

### 3. 正在建设的差异化能力

- **兼容性实测矩阵**：每天用固定 dsh 版本对 Top 100 插件真实安装冒烟，输出 verified/failed 徽章——目前头部目录都只做"收录"，没做"验证"
- **每周趋势周报**：新增插件、Star 飙升榜、分类变化，自动生成
- **收录徽章**：插件作者一键贴到自己 README，互相引流

### 4. 为什么值得关注

- 对开发者：找插件、比插件、装插件一站式
- 对插件作者：收录即曝光，还有官方徽章
- 对生态：全量数据 + 兼容验证，是社区的基础设施

### 5. 参与方式

- 给仓库点 Star：https://github.com/ukinch605/awesome-dsh-hub
- 插件作者：加 topic + 声明 bundle，1 小时自动收录
- 提交分类修正 / 功能建议：Issue / PR
